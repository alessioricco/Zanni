# Release notes style

- Start with `# What's new in <version>`, then one short sentence on the release.
- Two sections, in this order: `## New` for added features, `## Fixed` for fixes.
- One bullet per change, written for the people who use the product: what they can now do, or what no longer
  goes wrong. End each bullet with its issue number in brackets, such as `(#101)`.
- Plain words. No internal names, no "we refactored".
