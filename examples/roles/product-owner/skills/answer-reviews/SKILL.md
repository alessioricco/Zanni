# Answer reviews

1. Read every review in `reviews/round-<n>/` that is about the backlog: `backlog-<part>.md`.
2. For each point, decide: change the backlog, or keep it and say why. You decide; reviewers advise.
3. Rewrite `backlog/round-<n>.md` once, with the changes. Keep criterion ids stable: a criterion you keep keeps its id;
   a new one gets the next free number.
4. Write `reviews/round-<n>/backlog-answers.md`: one line per review point, what you did about it, and why.
