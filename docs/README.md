# Zanni docs

Zanni is an engine for teams of AI personas. Each actor plays a role defined in a folder; a director casts actors and coordinates them on a shared stage, following a play.

**Status:** early. `zanni <file>` validates files and shows what it would run. Nothing runs actors yet; see [ROADMAP.md](../ROADMAP.md).

- [Getting started](getting-started.md): install the package, and check your first file.
- [Zanni files](files.md): actor files, play files and role manifests.
- [Spec](spec/README.md): the formats and protocol, which other implementations can follow.
- [Spikes](spikes/): recorded experiments behind the decisions in [DECISIONS.md](../DECISIONS.md).
